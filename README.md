# Varietal Landing Page

A fast, responsive, single-page marketing site for an iOS app with a "Nordic Minimalist meets Science Lab" visual direction.

## Run locally

1. From the project directory, start a static server:
   - `python3 -m http.server 8080`
2. Open: `http://localhost:8080`

## Files

- `index.html` - semantic page structure and SEO metadata
- `styles.css` - design tokens, reusable components, responsive layout, and motion
- `script.js` - stagger/load animations and utility behavior
